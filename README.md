# Git Rules – FTC VishwaBot Team

## 🔒 Branch Policy
- `main` is PROTECTED
- No one pushes or merges directly to `main`
- Only the Team Lead merges PRs

## 🌿 Branch Naming
Create a new branch for every task:
- feature/mecanum-drive
- feature/odometry
- fix/encoder-direction
- vision/apriltag

## 🧑‍💻 Developer Workflow
1. Always start from `main`
   `bash
    git checkout main
    git pull`
